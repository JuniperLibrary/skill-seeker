# 预览功能测试文档

## 1. 测试环境准备

```bash
# 激活虚拟环境
.venv\Scripts\activate

# 启动应用
streamlit run skill_web.py
```

## 2. 测试流程

### 2.1 基本预览测试

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 打开浏览器访问 `http://localhost:8501` | 显示 Skill Seeker 主页 |
| 2 | 侧边栏选择 AI 提供商（如 Anthropic） | 显示 API Key 输入框 |
| 3 | 输入有效的 API Key | 滑块可用，增强等级可调 |
| 4 | 上传一个 PDF 文件 | 显示文件名和大小 |
| 5 | 点击 **🔍 预览** 按钮 | 显示进度条，执行解析 |
| 6 | 预览完成 | 显示大纲结构 |
| 7 | 点击 **🚀 确认执行** | 执行完整蒸馏 |
| 8 | 蒸馏完成 | 显示下载按钮 |

### 2.2 批量预览测试

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 选择"批量上传"模式 | 显示批量上传区域 |
| 2 | 上传多个文件 | 显示文件名列表 |
| 3 | 点击 **🔍 预览** | 解析所有文件 |
| 4 | 预览完成 | 显示所有文件的大纲 |
| 5 | 点击 **🚀 确认执行** | 批量执行蒸馏 |
| 6 | 全部完成 | 显示所有下载按钮 |

### 2.3 边界测试

| 场景 | 操作 | 预期结果 |
|------|------|----------|
| 未上传文件 | 点击预览 | 按钮禁用 |
| API Key 留空 | 点击预览 | 显示警告提示 |
| 预览失败 | 执行解析 | 显示错误信息 |

## 3. 检查清单

### 3.1 UI 检查

- [ ] 预览按钮在上传文件后启用
- [ ] 预览中按钮显示禁用状态
- [ ] 预览完成后显示大纲
- [ ] 确认执行按钮在预览后显示
- [ ] 执行完成后显示下载按钮

### 3.2 功能检查

- [ ] 预览使用 `--enhance-level 0`
- [ ] 确认执行使用用户选择的增强等级
- [ ] 预览目录正确生成
- [ ] 执行后预览目录被清理
- [ ] session_state 正确重置

### 3.3 错误处理

- [ ] 无文件时预览按钮禁用
- [ ] API Key 缺失时提示
- [ ] 解析失败时显示错误
- [ ] 执行失败时显示错误

## 4. 测试数据

### 4.1 测试文件

建议使用以下测试文件：

- `test_small.pdf` - 小于 1MB 的简单 PDF
- `test_docx.docx` - 包含多章节的 Word 文档
- `test_epub.epub` - 电子书格式

### 4.2 预期大纲结构

预览完成后应显示类似结构：

```
### My_Custom_Skill
**Document Information**
- Author: ...
- Created: ...
- ...
**When to Use This Skill**
- Understand concepts...
**Section Overview**
- Total Sections: N
- ...
```

## 5. 常见问题

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 预览按钮灰色 | 未上传文件 | 先上传文件 |
| 预览失败 | skill-seekers 错误 | 检查文件格式 |
| 执行失败 | API Key 无效 | 检查 API Key |
