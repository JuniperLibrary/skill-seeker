# 预览功能设计文档

## 1. 需求背景

**目标**: 蒸馏前预览 AI 增强后的 SKILL.md 大纲，确认后再执行，避免浪费时间和 API 调用。

**用户痛点**: 当前流程直接执行完整蒸馏，文件大/增强等级高时会消耗大量 API 配额，结果不满意也无法修改。

**技术说明**: `skill-seekers` 的 `--dry-run` 主要用于网页抓取预览。文档增强场景需要用两阶段方案实现：
- 阶段1: `--enhance-level 0` 先解析文档生成初始 SKILL.md
- 阶段2: 用户确认后，再用 `--enhance-level N` 执行完整 AI 增强

## 2. 技术方案

### 核心实现

利用 `skill-seekers create` 的 `--dry-run` 参数：
```
skill-seekers create <file> --dry-run
```

`--dry-run` 会在不调用 AI 的情况下生成增强后的大纲结构，供用户预览确认。

### 执行流程

```
1. 用户上传文档 → 2. 配置参数 → 3. 点击"预览" → 4. 展示大纲 → 5. 确认执行
```

### 按钮状态

| 状态 | 预览按钮 | 执行按钮 |
|------|----------|----------|
| 未上传 | 禁用 | 禁用 |
| 已上传 | 可点击 | 隐藏 |
| 预览中 | 禁用+loading | 隐藏 |
| 预览完成 | 可点击 | 显示 |
| 执行中 | 禁用 | 禁用+loading |
| 执行完成 | 重置 | 显示下载 |
