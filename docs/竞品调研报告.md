# Skill 蒸馏技术市场调研报告

## 调研时间

2026年4月

## 调研目的

了解市场上 Skill 蒸馏技术的实现方案，与本项目进行对比，分析差异点和待提升点。

## 市场竞品概览

### 1. Skill Seekers (官方)

- **定位**: CLI + MCP 全栈工具
- **支持输入源**: 18种（文档网站、GitHub仓库、PDF、视频、Jupyter等）
- **输出平台**: 12+（Claude、Gemini、OpenAI、LangChain、Cursor等）
- **特点**:
  - 官方CLI工具，功能最全
  - 支持MCP Server可直接在Claude中调用
  - 有预设配置市场（24+ preset）
  - 15-45分钟/ 每个Skill

### 2. Doc2Skill

- **定位**: 在线网站工具
- **支持输入**: 文档URL
- **输出平台**: Claude Skill
- **特点**:
  - 无需安装，网页直接使用
  - 支持AI增强
  - 处理时间最长20分钟

### 3. Any2Skills

- **定位**: 在线网站工具
- **支持输入**: Word、Excel、Markdown等多格式文档
- **输出平台**: Claude、ChatGPT Custom GPTs、OpenClaw
- **特点**:
  - 多格式支持
  - 支持批量上传
  - 目前仅限waitlist

### 4. pydstl (Python库)

- **定位**: Python开源库
- **支持输入**: 散乱知识（代码评审、笔记、文档片段）
- **输出格式**: 自定义Markdown格式
- **特点**:
  - 模型无关（支持任何pydantic-ai模型）
  - 使用SQLite+sqlite-vec做向量存储
  - 支持增量更新和合并

### 5. AI Distiller (aid)

- **定位**: Claude Code Skill
- **功能**: 从代码库提取公共API
- **特点**:
  - 依赖感知分析
  - 可减少90-98%代码量
  - 输出多种格式

## 本项目优势

1. **历史记录功能**
   - 竞品都没有此功能
   - 已领先实现
   - 支持重新下载、修改配置重新蒸馏

2. **批量处理功能**
   - 官方CLI反而没有此功能
   - 已领先实现
   - 支持多文件同时蒸馏

3. **Web UI界面**
   - 降低使用门槛
   - 无需命令行操作
   - 可视化配置

4. **多模型支持**
   - 支持8+国内AI模型
   - 智谱AI、通义千问、豆包、DeepSeek、千帆等

## 差异与待提升点

### 高优先级

1. **多源输入支持**
   - 现状：仅支持PDF/DOCX/EPub文件
   - 竞品：支持文档网站、GitHub仓库、视频、Notion等
   - 建议：后续添加爬虫功能

2. **MCP Server支持**
   - 现状：无
   - 竞品：官方Skill Seekers有MCP server
   - 建议：添加MCP server可直接在Claude中调用

### 中优先级

3. **RAG集成增强**
   - 现状：基础支持LangChain/Chroma输出
   - 竞品：更完善的RAG pipeline输出
   - 建议：增强向量检索和知识库构建

4. **预设模板市场**
   - 现状：无
   - 竞品：24+ preset配置
   - 建议：添加常用场景预设模板

5. **预览确认功能**
   - 现状：无
   - 竞品：无
   - 建议：蒸馏前预览大纲，确认后再执行

### 低优先级

6. **配置保存**
   - 现状：无，每次需重新输入
   - 竞品：无
   - 建议：保存常用配置

7. **进度实时推送**
   - 现状：轮询状态
   - 竞品：无
   - 建议：WebSocket推送进度

8. **社区/市场**
   - 现状：无
   - 竞品：有marketplace
   - 建议：搭建preset分享市场

## 总结

本项目在单文档蒸馏领域具有以下差异化优势：

1. ✅ 历史记录功能（竞品无）
2. ✅ 批量处理功能（官方CLI无）
3. ✅ Web UI降低门槛
4. ✅ 多模型支持（8+国内模型）

待提升方向：

1. 🚀 多源输入（文档网站、GitHub）
2. 🚀 MCP Server支持
3. 🚀 预设模板市场
4. 🚀 RAG集成增强
